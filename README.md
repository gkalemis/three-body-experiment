## Τι μπορείς να αλλάξεις

| Χειριστήριο | Λειτουργία |
|---|---|
| Διάταξη Α | Επιλογή από επτά έτοιμα σετ |
| Αλλαγή Β | Καμία αλλαγή, έτοιμες τιμές ή προσαρμογή με λογαριθμικό slider |
| Σχετική αλλαγή | Από 10⁻⁸ έως 10⁻¹, δηλαδή κλάσμα της μικρότερης αρχικής απόστασης |
| Κατεύθυνση | Οριζόντια ή κατακόρυφη |
| Τελικός χρόνος | Slider και συνδεδεμένο αριθμητικό πεδίο |
| Προβολή | 240, 480 ή 720 καρέ |
| Επαναφορά σετ | Επαναφορά διάρκειας, κατεύθυνσης και αρχικής μικρής αλλαγής |

Η Β δημιουργείται κάθε φορά από την Α. Οι αλλαγές δεν συσσωρεύονται. Μετακινούνται τα σώματα 1 και 2 αντίθετα, ώστε m₁Δr₁+m₂Δr₂=0. Η μεγαλύτερη από τις δύο μετατοπίσεις ισούται με το επιλεγμένο κλάσμα επί τη μικρότερη αρχική απόσταση. Οι μάζες και οι αρχικές ταχύτητες δεν αλλάζουν. Η συνολική ορμή παραμένει ίδια, αλλά η αρχική ενέργεια και η στροφορμή των Α και Β μπορεί να διαφέρουν.

Αλλαγή φυσικών ρυθμίσεων ακυρώνει το προηγούμενο αποτέλεσμα. Απαιτείται νέο **Υπολόγισε Α και Β**. Αλλαγή μόνο των καρέ χρειάζεται νέα **Προβολή κίνησης**, χωρίς επανάληψη της ολοκλήρωσης.

## Επτά έτοιμες επιλογές

| Κλειδί | Διάταξη | Προεπιλεγμένος τελικός χρόνος | Μέγιστος επιλέξιμος χρόνος |
|---|---|---:|---:|
| `euler_visible` | Ίσες μάζες σε περιστρεφόμενη ευθεία· αρχική επιλογή | 8 | 12 |
| `euler_long` | Η ίδια αρχική διάταξη Euler, μεγαλύτερη διάρκεια | 12 | 12 |
| `lagrange_stable` | Περιστρεφόμενο ισόπλευρο τρίγωνο, μάζες 0,001 / 0,01 / 1 | 30 | 60 |
| `lagrange_equal` | Περιστρεφόμενο ισόπλευρο τρίγωνο, ίσες μάζες | 10 | 12 |
| `euler` | Η ίδια αρχική διάταξη Euler, μικρότερη διάρκεια | 6 | 12 |
| `at_rest` | Ισόπλευρο τρίγωνο ίσων μαζών που ξεκινά ακίνητο | 1,4 | 3 |
| `burrau` | Αρχικά ακίνητα σώματα με μάζες 3 / 4 / 5 | 15,8 | 20 |

Ο ελάχιστος επιλέξιμος τελικός χρόνος είναι 0,05. Τα ανώτατα όρια είναι όρια εξερεύνησης, όχι εγγύηση αξιοπιστίας για κάθε επιλογή. Σε πολύ κοντινή προσέγγιση μπορεί να γίνει νωρίτερα διακοπή.

## Τι θα παρατηρήσεις

Στην οριζόντια αλλαγή 10⁻⁶, η Euler δίνει μέτρο διαφοράς D≈0,063 στο t=6, D≈0,860 στο t=8 και D≈2,400 στο t=12. Η απόκλιση είναι ορατή με κοινή κλίμακα για Α και Β. Αυτές είναι τιμές των καταγεγραμμένων εκτελέσεων, όχι γενικός κανόνας.

Η D είναι η μαζικά σταθμισμένη τετραγωνική μέση απόσταση των αντίστοιχων θέσεων, αφού αφαιρεθεί η θέση του κέντρου μάζας κάθε εκδοχής. Δεν είναι απόσταση δύο σωμάτων μέσα στο ίδιο σύστημα.

Η απόκλιση από ασταθή κίνηση **δεν αποδεικνύει από μόνη της χάος**. Η ακριβής αρχική κατάσταση καθορίζει μοναδικά την εξέλιξη όσο οι νευτώνειες εξισώσεις παραμένουν κανονικές. Η αβεβαιότητα μετρήσεων και τα αριθμητικά σφάλματα περιορίζουν την πρακτική πρόβλεψη.

## Κίνηση και μονάδες

Ο νέος player χρησιμοποιεί HTML Canvas και JavaScript με ενσωματωμένα δεδομένα, χωρίς εξωτερικό CDN ή FFmpeg. Περιλαμβάνει παύση, βήματα, επιλογή χρόνου, ταχύτητα, επανάληψη, ίχνη και δείκτη στο διάγραμμα D. Στο 1× όλο το διάστημα προβάλλεται σε περίπου 30 δευτερόλεπτα, ανεξάρτητα από τα καρέ. Πολύ σύντομα γεγονότα μπορεί να μη φαίνονται ανάμεσα στα καρέ.

Η διάρκεια του μοντέλου διαφέρει από τη διάρκεια προβολής. Χρησιμοποιούμε G=1 με κατάλληλη επιλογή μονάδων: T₀=√(L₀³/(G·M₀)). Για M₀=1 kg και L₀=1 m, μία μονάδα χρόνου είναι περίπου 34 ώρες. Το μοντέλο δεν αναπαριστά συγκεκριμένα άστρα.

### JupyterLab στον υπολογιστή σου

Από τη ρίζα του αποθετηρίου, εγκατάστησε τις εξαρτήσεις και το JupyterLab:

```bash
python -m pip install -r requirements.txt
python -m pip install jupyterlab
python -m jupyterlab
```

Στο παράθυρο του JupyterLab άνοιξε το `three_body.ipynb` και επίλεξε **Run → Run All Cells**. Χρησιμοποίησε kernel του ίδιου περιβάλλοντος Python στο οποίο εγκατέστησες τις εξαρτήσεις και το ipywidgets.

Αν τροποποιήσεις τις ενσωματωμένες πηγές, ανακατασκεύασε το notebook με:

```bash
python build_notebook.py
```

Η εντολή αντικαθιστά το notebook και δεν χρειάζεται για τη συνηθισμένη χρήση.

Οι νέες εκτελέσεις γράφουν `checks.json`, `trajectories.npz`, `comparison.png` και `motion.html` στον φάκελο `results/interactive/`. Αντικαθίστανται στην επόμενη εκτέλεση. Στο Colab είναι προσωρινά: κατέβασε όσα χρειάζεσαι πριν κλείσει η συνεδρία.

## Έλεγχοι και συντήρηση

Από τη ρίζα του αποθετηρίου:

```bash
python tests/validate_interactive.py
python tests/execute_standalone.py
```

Το πρώτο τεστ παράγει και όλα τα δεδομένα/HTML που χρειάζεται ο έλεγχος browser. Για χωριστό έλεγχο των widgets: `python tests/check_widgets.py`.

Προαιρετικά, για επαλήθευση του player σε Chromium:

```bash
npm install
npx playwright install chromium
npm run test:browser
```

Τα browser tests εντοπίζουν τα αποτελέσματα σχετικά με τον φάκελο του ίδιου του script, χωρίς εξάρτηση από το όνομα του εξωτερικού φακέλου. Οι εξαρτήσεις Node απαιτούνται μόνο για αυτά τα tests, όχι για την εφαρμογή. Το `player.html` είναι πρότυπο με δείκτη δεδομένων· άνοιξε το παραγόμενο `results/interactive/motion.html` για έτοιμη κίνηση.

Για μορφοποίηση των πηγών και ανακατασκευή του notebook:

```bash
python -m pip install -r requirements-dev.txt
python -m black *.py tests/*.py
npm run format:web
python build_notebook.py
```

Το notebook έχει 40 κελιά συνολικά, από τα οποία 18 περιέχουν κανονικό, αναγνώσιμο κώδικα. Ο builder δεν χρησιμοποιεί σειριοποιημένες πηγές μέσα σε `exec` και παράγει σταθερά IDs κελιών. Μετά από αλλαγή στα αρχεία Python ή στο πρότυπο HTML, ανακατασκεύασε και επανέλεγξε το notebook πριν το ανεβάσεις.
